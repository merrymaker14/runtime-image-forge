# Решение проблем

| Проблема | Действие |
| --- | --- |
| Нет архива движка | Вне Play Mode выберите **Tools > Runtime Image Forge > Install Windows Backend**, затем пересоберите Player. |
| Загрузка остановилась или не удалась | Проверьте интернет, место на диске и разрешение записи. Повторите через явную кнопку загрузки. Отменённая или неудачная загрузка не заменяет исправный файл модели. |
| Контрольная сумма модели не совпадает | Замените неисправную копию явной HTTPS-загрузкой или повторным импортом проверенного локального комплекта в соответствии с профилем. Профили «Только импорт» требуют локального импорта. Наличие файла не разрешает генерацию до проверки целостности. |
| Подготовка не удалась | Проверьте профиль, Windows x64, поддержку Vulkan на GPU и файлы движка. Конкретная причина указана в Unity Console или Player log. |
| Нативная зависимость отсутствует или устарела | Установите последнюю версию Microsoft Visual C++ 2015–2022 Redistributable (x64) с сайта Microsoft и перезапустите Unity или игру. Если сообщение останется, обновите драйвер видеокарты. |
| Путь содержит символическую ссылку или точку соединения | Перенесите проект, игру, пакет моделей или папку экспорта туда, куда путь ведёт без символических ссылок и точек соединения каталогов (junction). Это касается и папки данных приложения (`Application.persistentDataPath`), если её перенаправили через junction. Папки облачной синхронизации, например OneDrive, ссылками не считаются. |
| Следующий заказ после отмены идёт дольше | Отмена загрузки модели или идущей генерации выгружает нативный контекст модели, чтобы освободить память. Следующий заказ сначала заново загружает модель. Отмена задания, которое ещё ждёт в очереди, контекст не выгружает. |
| Подготовка ещё выполняется | Подготовка проверяет файлы модели, загружает нативный контекст модели и выполняет прогрев без сохранения. Показывайте этот этап до приёма заказов. |
| Отменённое задание ещё освобождает ресурсы | Отмена запрашивает остановку нативной операции и запрещает публикацию результата. Место в очереди остаётся занятым до освобождения ресурсов. Дождитесь завершения перед повторным использованием или освобождением движка. |
| Нативная библиотека не прошла проверку | Закройте игру или Editor. Если сообщается, что установленный движок повреждён, удалите папку его версии в `Application.persistentDataPath/RuntimeImageForge/Backends` и повторите подготовку. Если проверку не прошёл архив из комплекта, удалите `Assets/StreamingAssets/RuntimeImageForge/windows-vulkan.zip`, выберите **Tools > Runtime Image Forge > Install Windows Backend** и пересоберите Player. Установщик никогда не перезаписывает отличающийся существующий файл. |
| Уже загружена другая версия нативной библиотеки | Перезапустите игру или Editor перед загрузкой другой версии нативной библиотеки. |
| Задание завершено без картинки | Проверьте `ForgeGenerationJob.State` и `Error`: завершение включает ошибки и отмену. Сохраняйте прежнее успешное изображение в интерфейсе. |
| Очередь заполнена | Дождитесь завершения или отмените работу. Отменённое задание занимает место, пока движок его не освободит. |
| В прозрачном PNG остался фон | Назначьте профиль маски и отключите **Сохранять фон** для стиля. Проверьте контраст предмета и маску: края могут быть несовершенны. |
| Не работает экспорт рядом с игрой | Выберите persistent-data или доступную папку. Защищённая установка может запрещать запись. Посторонние существующие файлы сохраняются. |
| Экспортированный комплект изменён | Используйте другое имя или восстановите исходный комплект. Экспорт не перезаписывает изменённый комплект. |
| Не восстановился предмет | Храните PNG с исходным ключом кэша, рецептом и контрольной суммой. Копия записи инвентаря сама не копирует картинку. |
| MCP не видит генератор | Откройте сцену, войдите в Play Mode, выполните подготовку и разрешите Forge-операции для сеанса Editor. Повторите `forge_status`. |
| Старый ID задания MCP исчез | Сведения о заданиях ограничены и принадлежат сеансу сцены. Сохраняйте записи и PNG надолго; после перезагрузки получите новый ID сеанса. |

## Отмена и выгрузка

Передавайте cancellation token при подготовке и генерации. `CancelPreparation()` останавливает запуск; `CancelJob(id)` — незавершённое задание сцены. Отмена предотвращает публикацию нового результата. `ImageGenerationQueue.CloseAsync()` отменяет работу, ждёт освобождения движка и освобождает его. Не освобождайте движок отдельно, если им уже владеет очередь.

У текстур и спрайтов отдельное время жизни. Храните владельца `UnityPngImage`, пока они показаны, затем освобождайте на потоке Unity или через `DisposeAsync()`. При замене освобождайте старые изображения: кэш на диске не ограничивает количество текстур в игре.

## Требования и ограничения

Встроенная реализация поддерживает Windows x64; движков macOS, Linux, мобильных платформ и WebGL нет. Проверенная конфигурация — RTX 3060 Laptop GPU с 6 GB VRAM. Это проверенное оборудование, не обещание работы любого устройства с заданным объёмом памяти.

Веса моделей и нативные библиотеки кэшируются в `Application.persistentDataPath/RuntimeImageForge`, созданные PNG и коллекция демо — в `Application.persistentDataPath/ForgeArt`. В редакторе это папка постоянных данных для названий компании и продукта проекта, вне самого проекта. Чтобы удалить кэш моделей и изображений, удалите эти папки; смена названия компании или продукта начинает новый кэш.

Генерация и маска используют GPU вместе с игрой. Ограничивайте очередь и размеры, показывайте этап загрузки; измеряйте свою игру и оборудование. Большие диффузионные веса загружайте отдельно явным действием. Изображение может не соответствовать запрошенному предмету или отличаться качеством; маске может потребоваться ручная доработка.

Для поддержки укажите версию Unity, GPU и драйвер, ID и ревизию модели, параметры стиля, этап и относящуюся к нему ошибку Console или Player log. Перед передачей проверьте фрагменты журнала на личные пути и содержимое игры.
