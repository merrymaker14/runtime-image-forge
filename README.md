# Runtime Image Forge website

Product website and public documentation for Runtime Image Forge by Strange Euphoria XR.

The Unity runtime package is distributed separately. This repository contains the website, documentation and example output images; it does not contain the plugin source or model weights.

Run `npm ci` followed by `npm run build`. GitHub Pages serves the generated `docs` directory. Documentation sources are in `content`; site files are in `public`.

Model and component terms are described in the published third-party notices. Example images were generated locally with the Bonsai Ternary 4B profile and U2NETP cutout in The Ember Forge.
