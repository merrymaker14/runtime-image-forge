Your first order

  1. Download the Windows game, extract the whole folder and launch it.
  2. Use the game's explicit download or import action for the selected model.
  3. Wait for verification and warmup, then craft your first item.
  4. Select it in the collection and save PNG + recipe.

Keep what you make

The collection saves up to 256 items, four per page. Export beside the game or into its data folder. Failed and cancelled orders do not add items.

Local models.
Practical limits.

Model weights are obtained separately: the free Bonsai model pack from The Ember Forge page or an explicit HTTPS download for Klein. After setup, generation runs offline on the player's machine. Hardware, resolution and other GPU workloads affect preparation and generation.

Unity and platform
Unity 6000.5 or later. Supplied backend: Windows x64 Vulkan DLLs running inside Unity; requires the Microsoft Visual C++ 2015–2022 Redistributable (x64). Foreground processing uses GPU Compute.
Tested hardware
NVIDIA RTX 3060 Laptop GPU, 6 GB VRAM. This is a tested configuration, not a guaranteed minimum.
Included model profiles
Bonsai Ternary 4B and FLUX.2 Klein 4B with U2NETP cutout. NativeDistilled1024 presets use 1024 × 1024, 4 steps and CFG 1. Pinned weights: Bonsai 4.64 GB (4.32 GiB), Klein 5.21 GB (4.85 GiB); engine and temporary space are additional.
What to expect
2D images. Requested details and fine cutout edges can be imperfect. Pixel-inspired prompts do not enforce a pixel grid.

Bonsai, Klein and U2NETP use Apache-2.0. Review the component and model terms for your use and distribution.
