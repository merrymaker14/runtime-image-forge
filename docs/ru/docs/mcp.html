Runtime Image Forge 1.0.0 · Unity 6000.5+

Инструменты агента в редакторе (MCP)

Необязательная интеграция использует MCP-сервер Unity CLI и com.unity.pipeline 0.8.0-exp.1 или новее. Её сборка компилируется только при наличии этого пакета. Для генерации и экспорта в игре Runtime Image Forge MCP не нужен.

  1. Установите Unity CLI и Pipeline в проект.
  2. Откройте Tools → Runtime Image Forge → Agent tools (MCP). Скопируйте конфигурацию клиента и разрешите создание, отмену и экспорт Forge для текущего сеанса редактора.
  3. Откройте сцену с ForgeGenerator и настроенным источником движка. Войдите в Play Mode и подготовьте генератор через интерфейс игры. Загрузка модели требует явного действия в этом интерфейсе.
  4. Подключите MCP-клиент. Команда сервера: unity mcp --project-path <absolute project path>.
Команда Назначение
forge_status ID сеансов генераторов сцены и их готовность.
forge_styles GUID редактируемых стилей и разрешённые варианты в порядке полей.
forge_generate GUID стиля, упорядоченные ключи вариантов, неотрицательный seed и необязательный background_mode. Немедленно возвращает ID задания.
forge_job_status Состояния queued, running, completed, cancelled, failed и текущий этап.
forge_cancel Отмена задания выбранного генератора.
forge_export Экспорт PNG и рецепта готового задания в Assets/Generated/RuntimeImageForge с импортом.

Передавайте generator_id, если в сцене несколько генераторов. ID сеанса относится к одному живому компоненту; запрашивайте его снова после выхода из Play Mode или перезагрузки сцены. Генератор хранит сведения максимум о 64 последних заданиях; очередь генерации ограничена отдельно. PNG остаются на диске.

Команды Forge не принимают произвольные пути экспорта, не меняют профили, не загружают веса и не устанавливают пакеты. Модели и стили настраиваются обычными инспекторами Unity. background_mode принимает style по умолчанию, transparent или keep; это переопределение одного заказа, не изменение стиля. Статус задания включает применённое remove_background. Режим входит в рецепт и ключ кэша. Для прозрачного заказа нужна назначенная модель маски.

MCP-подключение Unity также предоставляет общие команды редактора. Подключайте доверенных клиентов и используйте их настройки разрешений. Инструменты Forge работают только в Editor и исключены из сборки игры. Экспорт для игроков использует PngExporter без сетевой службы и MCP-клиента.
