Документация Runtime Image Forge

Runtime Image Forge создаёт локальные PNG по вариантам, заданным в вашей игре. Нативный движок DLL работает внутри процесса Unity в Windows x64 на GPU с Vulkan. Необязательная модель маски превращает отдельные предметы в изображения с прозрачным фоном.

Руководство Содержание
Быстрый старт Установка, профили, компоненты сцены и первое изображение.
Модели и стили Каталоги вариантов, визуальный стиль, идентификаторы моделей и фон.
Runtime API Подготовка, очередь, отмена, владение изображениями и собственные движки.
Сохранение и экспорт Прозрачные PNG, рецепты, папки и обмен.
MCP в редакторе Подключение, шесть команд Forge и разделение Editor/Player.
Решение проблем Загрузка, готовность, GPU, отмена и ошибки файлов.
Лицензии компонентов Закреплённые версии компонентов и тексты лицензий.

The Ember Forge входит в пакет как редактируемый пример: сцена, игровой код, оформление и музыка. Отдельная Windows-сборка позволяет играть без Unity и плагина.

Редактор, сайт и руководства доступны на английском, русском, испанском и упрощённом китайском. Выберите Язык редактора в окне или инспекторе Forge. Кнопки документации открывают руководство на выбранном языке. Переключение меняет интерфейс, сохраняя запросы к модели и настройки игры.
