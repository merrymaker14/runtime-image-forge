The Ember Forge

小小工坊，属于你的收藏。

选择剑、盾牌、戒指或护符，挑选材料与装饰，锻造图片并收藏。保存透明 PNG 和配方，即可分享成果。

Unity 包包含完整可编辑配套游戏： 场景、游戏源码、工坊美术和配乐。需要学习或修改时，可从 Samples 导入。 在 Unity 中打开随附游戏。

查看随附游戏的设置

你的第一份订单

  1. 下载 Windows 版游戏，解压完整文件夹并启动游戏。
  2. 为所选模型使用游戏中的显式下载或导入操作。
  3. 等待校验和预热完成，再制作第一个物品。
  4. 在收藏中选中物品，保存 PNG + 配方。

留住你的作品

收藏最多保存 256 件物品，每页四件。可导出到游戏旁边或游戏数据目录。失败和取消的订单不会新增物品。

游戏界面为英语。附带英语、俄语、西班牙语和简体中文的首次启动说明。独立游戏无需购买插件或安装 Unity。

本地模型。
实际限制。

权重单独获取：Bonsai 使用免费模型包，可从 The Ember Forge 页面 下载；Klein 使用显式 HTTPS 下载。设置完成后可在玩家电脑上离线生成。硬件、分辨率及其他 GPU 任务会影响准备和生成。

Unity 与平台
Unity 6000.5 或更新版本。随附后端：在 Unity 内运行的 Windows x64 Vulkan DLL；需要 Microsoft Visual C++ 2015–2022 Redistributable (x64)。前景处理使用 GPU Compute。
已测试硬件
NVIDIA RTX 3060 Laptop GPU，6 GB VRAM。这是已测试配置，并非保证可运行的最低要求。
随附模型配置
Bonsai Ternary 4B 与 FLUX.2 Klein 4B 配合 U2NETP 抠图。NativeDistilled1024 预设使用 1024 × 1024、4 步、CFG 1。固定权重：Bonsai 4.64 GB（4.32 GiB），Klein 5.21 GB（4.85 GiB）；引擎及临时文件空间另计。
效果预期
输出为 2D 图片。请求的细节和精细抠图边缘可能不准确。像素风提示词不会强制形成像素网格。

Bonsai、Klein 与 U2NETP 使用 Apache-2.0。请阅读 组件与模型条款 ，再决定如何使用与分发。
