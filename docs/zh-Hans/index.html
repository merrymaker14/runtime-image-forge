Editor MCP 工具

The Ember Forge

小小工坊，属于你的收藏。

选择剑、盾牌、戒指或护符，挑选材料与装饰，锻造图片并收藏。保存透明 PNG 和配方，即可分享成果。

Unity 包包含完整可编辑配套游戏： 场景、游戏源码、工坊美术和 FLUX.2 Klein 4B 模型配置，位于软件包的 Samples 文件夹，可直接学习或修改。 在 Unity 中打开随附游戏。

查看随附游戏的设置

无需 Unity 即可游玩。 The Ember Forge Windows 版下载仅 80 MB。需要 Windows x64 和支持 Vulkan 的 GPU；首次启动时会从 Hugging Face 下载 FLUX.2 Klein 4B（5.21 GB），之后可离线运行。

下载 Windows 版 · 80 MB

你的第一份订单

  1. 在 Unity 中选择 Tools > Runtime Image Forge > Open The Ember Forge sample。
  2. 进入播放模式，选择一次 DOWNLOAD MODEL。
  3. 等待校验和预热完成，再制作第一个物品。
  4. 在收藏中选中物品，保存 PNG + 配方。

留住你的作品

收藏最多保存 256 件物品，每页四件。可导出到游戏旁边或游戏数据目录。失败和取消的订单不会新增物品。

示例游戏界面为英语。编辑器窗口和指南提供英语、俄语、西班牙语和简体中文版本。

本地模型。
实际限制。

模型权重需单独下载：随附的 FLUX.2 Klein 4B 配置仅在显式执行下载操作时通过 HTTPS 获取三个固定文件。设置完成后可在玩家电脑上离线生成。硬件、分辨率及其他 GPU 任务会影响准备和生成。

Unity 与平台
Unity 6000.5 或更新版本。随附后端：在 Unity 内运行的 Windows x64 Vulkan DLL；需要 Microsoft Visual C++ 2015–2022 Redistributable (x64)。前景处理使用 GPU Compute。
已测试硬件
NVIDIA RTX 3060 Laptop GPU，6 GB VRAM。这是已测试配置，并非保证可运行的最低要求。
随附模型配置
FLUX.2 Klein 4B；U2NETP 抠图模型按需安装，不包含在软件包中。随附的五种样式使用 1024 × 1024、4 步、CFG 1。固定权重：5.21 GB（4.85 GiB）；引擎及临时文件空间另计。
效果预期
输出为 2D 图片。请求的细节和精细抠图边缘可能不准确。像素风提示词不会强制形成像素网格。

FLUX.2 Klein 4B 与 U2NETP 使用 Apache-2.0。请阅读 组件与模型条款 ，再决定如何使用与分发。
