第三方组件与模型条款

Runtime Image Forge 随附基于 stable-diffusion.cpp、revision f89d9b13d730eabeede7314ce49dacd18d3c90c2 修改的 Windows x64 Vulkan 原生库。原生 DLL 在 Unity 进程内运行，并从所选模型读取 FLUX.2 VAE 归一化参数。安装器和加载器会校验随附本地库的固定 SHA-256。重新分发此后端的应用应保留随附声明。

完整原文位于 ThirdParty。Tools → Runtime Image Forge → Install Windows Backend 将固定版本的 DLL 打包为 Assets/StreamingAssets/RuntimeImageForge 中的压缩包，并把这些声明复制到该处，供游戏构建使用。命令会保留内容不同的现有文件，不会覆盖。

本包不包含背景移除模型。应开发者请求，Tools → Runtime Image Forge → Install Foreground Model（Overview 和前景配置的 Inspector 中也有该按钮）会下载 rembg v0.0.0 发布版中提供的 Xuebin Qin 的 U²-Netp ONNX 导出（u2netp.onnx，4,574,861 字节，SHA-256 309c8469258dda742793dce0ebea8e6dd393174f89934733ecc8b14c76f4ddd8），以及固定修订版本中的 U²-Net Apache 2.0 许可证（LICENSE，11,357 字节，SHA-256 c71d239df91726fc519c6eb72d318ec65820627232b2f796219e87dcf35d0ab4）。它会连同声明保存到 Assets/RuntimeImageForge/ForegroundModel，并把许可证和声明复制到 Assets/StreamingAssets/RuntimeImageForge/Licenses 供游戏构建使用。同名但内容不同的现有模型或许可证文件会被保留；声明文件由该命令生成，会被重写。它预测显著前景对象；复杂场景和精细边缘可能需要其他抠图模型。

Bonsai Ternary 4B 和 FLUX.2 Klein 4B 以组件配置预设随附。权重文件与 Unity 软件包分开获取：Bonsai 需要兼容的已转换本地模型包；Klein 支持显式下载固定 HTTPS 组件或本地导入。
