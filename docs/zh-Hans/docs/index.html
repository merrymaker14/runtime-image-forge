Runtime Image Forge 文档

Runtime Image Forge 根据游戏预先定义的选项，在本地生成 PNG。原生 DLL 后端在 Windows x64 的 Unity 进程内使用 Vulkan GPU 运行。可选前景模型可为独立物品生成透明背景图像。

指南 内容
快速入门 安装、配置、场景组件与第一张图像。
模型和风格 选项目录、视觉方向、模型标识与背景策略。
运行时 API 准备、有界任务、取消、图像生命周期与自定义后端。
保存与导出 透明 PNG、配方、文件夹与分享。
编辑器 MCP 连接、六个 Forge 命令与 Editor/Player 边界。
故障排查 下载、就绪、GPU、取消与文件错误。
第三方声明 固定组件版本与许可证文本。

The Ember Forge 作为可编辑示例随软件包提供，包括场景、游戏代码、美术和音乐。独立 Windows 下载版无需 Unity 或此软件包即可游玩。

编辑器、网站与指南提供英语、俄语、西班牙语和简体中文。在 Forge 窗口或 Inspector 中选择编辑器语言，文档按钮会打开相应指南。切换语言只改变界面呈现，不改变模型提示词或游戏设置。
