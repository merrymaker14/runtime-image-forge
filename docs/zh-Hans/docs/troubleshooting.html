故障排查

  • 取消与卸载
  • 要求与限制
症状 处理
原生归档缺失 退出播放模式，选择 Tools > Runtime Image Forge > Install Windows Backend，再重新构建 Player。
下载中断或失败 检查网络、磁盘空间与写入权限，通过主动下载操作重试。取消或失败的下载不会替换有效模型。
模型校验失败 根据配置，通过显式 HTTPS 下载或重新导入经过验证的本地模型包来替换无效副本。仅导入配置必须使用本地导入。文件存在不代表可生成，需先通过完整性检查。
准备失败 检查配置、Windows x64、Vulkan GPU 支持与原生文件，在 Console 或 Player log 查看具体原因。
原生依赖缺失或版本过旧 从 Microsoft 安装最新的 Microsoft Visual C++ 2015–2022 Redistributable (x64)，然后重启 Unity 或游戏。如果仍有提示，请更新显卡驱动。
路径包含符号链接或目录联接 把项目、游戏、模型包或导出文件夹移动到路径中不含符号链接和目录联接的位置。如果应用数据文件夹（Application.persistentDataPath）通过目录联接重定向，也需要这样处理。OneDrive 等云同步文件夹不视为链接。
取消后的下一个订单较慢 取消正在进行的模型加载或生成会卸载原生模型上下文以释放内存。下一个订单在生成前会重新加载模型。取消仍在队列中等待的任务不会卸载上下文。
准备仍在进行 准备会校验 checkpoint、加载原生模型上下文并进行不保存图像的预热。接受订单前显示此阶段。
已取消的任务仍在释放资源 取消会请求原生操作停止，并阻止发布结果。原生工作释放资源前仍占用队列位置。请等待完成后再重用或释放后端。
原生库校验失败 关闭游戏或 Editor。如果提示已安装的后端已损坏，请删除 Application.persistentDataPath/RuntimeImageForge/Backends 下对应版本的文件夹，然后重新准备。如果随附的归档未通过校验，请删除 Assets/StreamingAssets/RuntimeImageForge/windows-vulkan.zip，选择 Tools > Runtime Image Forge > Install Windows Backend 并重新构建 Player。安装器从不覆盖已存在的不同文件。
已加载另一个原生库版本 加载其他原生库版本前，请重启游戏或 Editor。
任务完成但没有图像 检查 ForgeGenerationJob.State 与 Error，完成也包括失败或取消。界面应保留上一张成功图像。
队列容量已满 等待任务完成或取消。取消任务在后端释放前仍占用槽位。
透明 PNG 仍有背景 分配前景配置并关闭风格的保留背景。检查生成物体对比度和蒙版，预测可能留下不完善边缘。
无法导出到游戏旁 选择持久数据目录或可写文件夹。受保护目录可能禁止写入，已有无关文件会保留。
导出组合包被修改 换名称或恢复原始组合包。导出器拒绝覆盖已修改组合包。
恢复物品时图像缺失 同时保留原始缓存键、配方、内容哈希与 PNG。只复制库存记录不会复制图像。
MCP 找不到生成器 打开配置场景，进入播放模式并准备，允许当前 Editor 会话的 Forge 操作，再查询 forge_status。
旧 MCP 任务 ID 消失 元数据有数量限制并属于单一场景会话。长期保存记录与 PNG，重载后获取新会话 ID。

取消与卸载

准备与生成时传入取消令牌。CancelPreparation() 停止启动工作，CancelJob(id) 取消未完成场景任务。取消会阻止新结果发布。ImageGenerationQueue.CloseAsync() 取消任务，等待后端释放后销毁后端。不要单独释放已由队列拥有的后端。

纹理和精灵有各自生命周期。显示期间保留 UnityPngImage，之后在 Unity 线程释放或使用 DisposeAsync()。替换图像时释放旧图像，磁盘缓存并不会限制游戏保留的纹理数量。

要求与限制

随附本地实现支持 Windows x64，不提供 macOS、Linux、移动或 WebGL 后端。已测试配置为 RTX 3060 Laptop GPU、6 GB VRAM。这是测试配置，不保证所有具有特定内存大小的设备都能运行。

模型权重和原生库缓存在 Application.persistentDataPath/RuntimeImageForge，生成的 PNG 和配套游戏收藏保存在 Application.persistentDataPath/ForgeArt。在编辑器中，这是项目公司名和产品名对应的持久数据文件夹，位于项目之外。删除这些文件夹即可移除缓存的模型和图片；更改公司名或产品名会开始新的缓存。

生成与前景处理和游戏共享 GPU 资源。使用有界队列、适度尺寸与明确加载阶段，并测试目标游戏和硬件。大型扩散权重应由玩家主动单独下载。生成像素可能没有正确呈现所请求对象或质量不同，抠图也可能需要手动清理。

请求支持时提供 Unity 版本、GPU/驱动、模型 ID/版本、风格设置、阶段和相关 Console 或 Player log 错误。分享日志前请检查私人路径或游戏内容。
