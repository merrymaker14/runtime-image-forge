Componentes de terceros y condiciones de los modelos

Runtime Image Forge incluye bibliotecas nativas modificadas para Windows x64 Vulkan basadas en stable-diffusion.cpp, revisión f89d9b13d730eabeede7314ce49dacd18d3c90c2. La DLL nativa se ejecuta dentro del proceso Unity y lee los parámetros de normalización de FLUX.2 VAE del modelo seleccionado. El instalador y el cargador verifican las bibliotecas locales incluidas con sus SHA-256 fijados. Conserva los avisos incluidos en las aplicaciones que redistribuyan este motor.

Tools → Runtime Image Forge → Install Windows Backend copia esos avisos y el archivo fijado a Assets/StreamingAssets/RuntimeImageForge para las compilaciones del juego. El comando conserva los archivos existentes que sean diferentes, sin sobrescribirlos.

El pequeño modelo de eliminación de fondo incluido en el paquete es una exportación ONNX de U²-Netp de Xuebin Qin, Apache 2.0. Su origen, suma de comprobación del checkpoint, detalles de exportación y licencia completa están junto a Runtime/Models/U2NetP-320.onnx y en los avisos copiados. Predice un objeto destacado en primer plano; las escenas complejas y los bordes finos pueden requerir otro modelo de recorte.

Bonsai Ternary 4B y FLUX.2 Klein 4B se incluyen como presets de perfiles por componentes. Los pesos son independientes del paquete de Unity: Bonsai requiere un paquete local convertido compatible; Klein permite descargas explícitas de sus componentes HTTPS fijados o importación local.
