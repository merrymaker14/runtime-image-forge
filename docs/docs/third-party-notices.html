Third-party components and model terms

Runtime Image Forge includes modified Windows x64 Vulkan native libraries based on stable-diffusion.cpp, revision f89d9b13d730eabeede7314ce49dacd18d3c90c2. The native DLL runs inside the Unity process and reads FLUX.2 VAE normalization parameters from the selected model. The installer and loader verify the supplied local library files against pinned SHA-256 checksums. Keep the supplied notices with applications that redistribute this backend.

The small foreground-removal model included in the package is an ONNX export of Xuebin Qin's U²-Netp, Apache 2.0. Its source, checkpoint checksum, export details and complete license are beside Runtime/Models/U2NetP-320.onnx and in the copied notices. It predicts a salient foreground object; complex scenes and fine edges can need a different cutout model.

Bonsai Ternary 4B and FLUX.2 Klein 4B are supplied as component-profile presets. Weight files are separate from the Unity package: Bonsai requires a compatible converted local pack; Klein permits explicit downloads of its pinned HTTPS components or local import.
